# Code of conduct

## Our standard

We are committed to a respectful, harassment-free project. Be constructive,
assume good intent while addressing harmful impact, and focus criticism on the
work rather than the person.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
intimidation, sexualized content, publishing private information, and sustained
disruption of project spaces.

## Enforcement

Report conduct concerns privately to the maintainer through an available GitHub
private reporting channel. The maintainer may edit or remove content and may
temporarily or permanently restrict participation when necessary.

Enforcement decisions should protect affected participants, minimize exposure
of private information, and document public outcomes only when appropriate.

This policy applies in repository spaces and when someone publicly represents
the project.
