## Observed difference

Both attempts ran a Windows setup step that replaced rustup 1.29.0 with 1.28.2.
In the failed attempt, `rustup-init.exe` could not remove `rustup.exe` because
another process was using the file. Windows reported OS error 32 and the setup
step exited with code 1.

In the successful attempt, the same replacement step completed and reported
`Rust is installed now. Great!` before the workflow continued to the Rust
toolchain action and tests.
