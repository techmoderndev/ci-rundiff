# Governance

CI RunDiff currently uses a single-maintainer model.

## Roles

- **Maintainer:** reviews and merges changes, publishes releases, handles
  security reports, and documents project decisions.
- **Contributor:** submits issues, examples, documentation, code, or reviews.

The current maintainer is the `techmoderndev` GitHub account.

## Decisions

Small, reversible decisions are made in pull requests. Significant changes to
privacy, scope, dependencies, output guarantees, or governance require a public
issue and a documented rationale before implementation.

No contribution count, employer, or financial sponsorship grants automatic
merge or release authority. Additional maintainers may be invited after a
sustained record of technical contributions, respectful review, and alignment
with the project's evidence-first trust model.
